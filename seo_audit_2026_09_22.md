## 2. Top 5 Recommended Improvements

1. **SEO-001 (HIGH - Privacy & Crawl Budget)**: **Add `noindex, nofollow` to Private Pages & Add `/track/` to Robots Disallow.**
   * *Impact*: Dynamic customer order tracking URLs (`/track/[orderId]`) contain customer names, delivery windows, and itemized garment lists. They lack `noindex` directives and are not disallowed in `robots.txt`. If shared in public forums, Google could index sensitive customer tracking screens. Login, signup, and portal pages also lack explicit `noindex` directives.
2. **SEO-002 (HIGH - Canonical Integrity)**: **Add Self-Referencing Canonical Tags to All Public Pages.**
   * *Impact*: `<link rel="canonical">` is currently absent from the raw HTML of every public page. Inbound links with marketing query parameters (`?utm_source=...`), capitalization variants, or trailing slashes risk duplicate content penalties and page rank dilution.
3. **SEO-003 (HIGH - Social Previews)**: **Fix Missing `og:image` on Subpages Caused by OpenGraph Override.**
   * *Impact*: In Next.js App Router, defining page-level `openGraph: { title, description }` without `images` overwrites the root image. Sharing `/pricing`, `/service-areas`, `/commercial`, or `/book` on WhatsApp, iMessage, LinkedIn, or Slack currently produces a preview card with **no thumbnail image**.
4. **SEO-004 (MEDIUM - SERP Snippets)**: **Eliminate Double Brand Suffix in Page Titles (`%s | First Eleven Cleaners | First Eleven Cleaners`).**
   * *Impact*: Root layout defines a title template `%s | First Eleven Cleaners`. Subpages explicitly append `| First Eleven Cleaners` in their title string, resulting in 84+ character titles that Google truncates in search results.
5. **SEO-005 (MEDIUM - Indexing Resilience)**: **Default `getAppBaseUrl()` to `https://firstelevencleaners.com` in Production.**
   * *Impact*: When `NEXT_PUBLIC_APP_URL` is unset, `getAppBaseUrl()` falls back to `http://localhost:3000`, causing `sitemap.xml` and `robots.txt` to serve `localhost:3000` URLs to web crawlers in non-Vercel production environments.

### SEO-002: Missing `<link rel="canonical">` Tags on All Public Pages
* **Severity**: HIGH
* **Section**: 3. Canonicals and URL Consistency
* **Location**: [`src/app/layout.tsx:26-88`](file:///d:/projects/first%20eleven%20cleaners/web/src/app/layout.tsx#L26-L88) and all public route layouts/pages.
* **What's Wrong**: Next.js App Router only renders `<link rel="canonical" href="...">` if `alternates: { canonical: '...' }` is explicitly provided in metadata. Although `metadataBase: new URL('https://firstelevencleaners.com')` is set in root layout, none of the public pages define `alternates.canonical`.
* **Plain-Language Impact**: When links are shared with campaign parameters (`?utm_source=...`, `?fbclid=...`, `?promo=...`), search engines treat each unique parameter string as a separate page, dividing ranking authority and risking duplicate content penalties.
* **Minimal Complete Fix**:
  1. In `src/app/layout.tsx`, add `alternates: { canonical: '/' }`.
  2. In each public page/layout (`/pricing`, `/service-areas`, `/about`, `/commercial`, `/book`, `/privacy`, `/terms`), add `alternates: { canonical: '/<route>' }`.
* **Other Places Pattern Appears**: 0 out of 8 public pages currently have canonical tags.
* **How to Verify**: Run `curl.exe -s http://localhost:3000/pricing | Select-String "canonical"`; confirm `<link rel="canonical" href="https://firstelevencleaners.com/pricing" />`.
* **Verification Tool**: Schema Markup Validator / GSC URL Inspection.
* **Confidence**: VERIFIED.

### SEO-003: Missing `og:image` on Subpages Caused by OpenGraph Override
* **Severity**: HIGH
* **Section**: 6. Social and Link Previews
* **Location**: [`src/app/pricing/layout.tsx:7-12`](file:///d:/projects/first%20eleven%20cleaners/web/src/app/pricing/layout.tsx#L7-L12), [`src/app/service-areas/page.tsx:11-16`](file:///d:/projects/first%20eleven%20cleaners/web/src/app/service-areas/page.tsx#L11-L16), [`src/app/commercial/layout.tsx:7-12`](file:///d:/projects/first%20eleven%20cleaners/web/src/app/commercial/layout.tsx#L7-L12), [`src/app/book/layout.tsx:7-12`](file:///d:/projects/first%20eleven%20cleaners/web/src/app/book/layout.tsx#L7-L12)

When a child layout defines `openGraph: { title: '...', description: '...' }`, it completely replaces the root `openGraph` object, discarding `images: ['/og-image.jpg']`. Raw HTML inspection confirms `og:image` is completely missing on `/pricing`, `/service-areas`, `/commercial`, and `/book`.
* **Plain-Language Impact**: When users share links to Pricing, Service Areas, or Booking on WhatsApp, LinkedIn, iMessage, or X, the link preview renders with **no image**, appearing blank or broken.
* **Minimal Complete Fix**: Add `images: ['/og-image.jpg']` (or specific 1200x630 cards) to `openGraph` in `pricing/layout.tsx`, `service-areas/page.tsx`, `commercial/layout.tsx`, and `book/layout.tsx`.
* **Other Places Pattern Appears**: `/privacy`, `/terms`, and `/about` did not redefine `openGraph` so they inherited the root image.
* **How to Verify**: Curl `/pricing` and check for `<meta property="og:image" content="https://firstelevencleaners.com/og-image.jpg" />`.
* **Verification Tool**: Facebook Sharing Debugger (`https://developers.facebook.com/tools/debug/`), LinkedIn Post Inspector.
* **Confidence**: VERIFIED.

## 8. Client Summary (Non-Technical)

### Overview
First Eleven Cleaners has a fast, modern website built on Next.js that pre-renders full content for Google and other search engines before JavaScript loads. Search engine crawlers and social media bots can easily read your headlines, service descriptions, and pricing without running heavy scripts.

### Key Risks Identified & Next Steps
1. **Customer Tracking Privacy Risk**: Live order tracking links (`/track/...`) created for customers via SMS do not currently have a "do not index" tag. If a customer pastes their tracking link into a public post or email, Google could index their order screen. We are adding an immediate block so search engines never index order tracking pages.
2. **Missing Thumbnail Images on Social Shares**: When someone shares your Pricing, Service Areas, or Booking pages on WhatsApp, iMessage, or LinkedIn, the link preview currently shows text with no picture. We need to attach your official preview image to all subpages.
3. **Missing Canonical Tags**: Your website does not currently tell Google which version of a page is the official master copy. Adding canonical tags ensures marketing links and ad campaigns do not split your SEO authority.
